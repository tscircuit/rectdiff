The gap-fill stages consume finite input queues, one item per iteration, then
need one final step to mark completion. A size-independent inherited limit can
reject an otherwise completed enumeration.

Two deterministic cases cover both queues: a 114 by 114 two-layer grid (103,968
edges, 912 exterior segments), and 100,001 clipped boundary seeds. The stacked
fix derives each limit from its queue length, including the final completion
step. It does not change geometry, queue order, or expansion strategy.

The inspected completed-grid snapshot is generated by
`scripts/export-finite-edge-visual.ts`. Both PRs link this expected result;
the reproduction does not claim that the unfixed solver completed it.

Local validation uses Bun 1.4.0 and solver-utils 0.0.23 on shared 4-vCPU hardware.
The base stops with 3,968 grid edges remaining; the fix passes both queue tests.
The Blacksmith workflow records pinned base/head queue results and the repository's
full canonical routing benchmark. Hosted results must be added before merging.
The board-sized all-fixed-copper experiment advances past both queue limits but
subsequently exhausts memory during topology merging; this fix alone does not
establish completion of the AM3352 board.
